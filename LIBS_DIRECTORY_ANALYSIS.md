# Анализ директории m7-jellyfin/libs

## 📁 Структура директории

```
libs/
├── movian/                    (26 файлов)
│   ├── *.d.ts               (TypeScript определения)
│   └── *.js.examples.js       (Примеры использования)
├── native/                   (27 файлов)
│   └── (нативные модули)
└── movian.d.ts             (Основные интерфейсы)
```

## 🎯 Основной файл: movian.d.ts

**Назначение:** Центральный файл с основными интерфейсами Movian API

**Содержит:**
- ✅ `Console` - логирование в консоль
- ✅ `Plugin` - метаданные плагина
- ✅ `VideoParams` - параметры видео (ключевой для canonicalUrl)
- ✅ `VideoSource` - источники видео
- ✅ `VideoSubtitle` - субтитры

**Почему НЕ содержит Item/Page:**
Эти интерфейсы находятся в `movian/page.d.ts` для модульности!

## 📂 Поддиректория movian/

| Файл | Назначение | Ключевые интерфейсы |
|-------|-----------|------------------|
| `page.d.ts` | Страницы и элементы | `Page`, `Item`, `ItemMetadata`, `VideoMetadata` |

| `sqlite.d.ts` | База данных | `SQLite`, `SQLiteInstance` |
| `prop.d.ts` | Свойства | `PropValue` |
| `html.d.ts` | HTML парсинг | HTML интерфейсы |
| `xml.d.ts` | XML обработка | XML интерфейсы |
| `subtitles.d.ts` | Субтитры | Субтитр интерфейсы |
| `store.d.ts` | Хранилище | Store интерфейсы |
| `itemhook.d.ts` | Хуки элементов | ItemHook интерфейсы |
| `popup.d.ts` | Всплывающие окна | Popup интерфейсы |
| `service.d.ts` | Сервисы | Service интерфейсы |
| `videoscrobbler.d.ts` | Видео скробблер | Scrobbler интерфейсы |
| `xmlrpc.d.ts` | XML-RPC | XML-RPC интерфейсы |

### 📚 Примеры использования (*.js.examples.js)

Каждому `.d.ts` файлу соответствует `.js.examples.js` с практическими примерами:

- `http.js.examples.js` - примеры HTTP запросов
- `page.js.examples.js` - примеры работы со страницами
- `settings.js.examples.js` - примеры настроек
- `sqlite.js.examples.js` - примеры работы с SQLite
- И т.д. для всех модулей

## 🚀 Рекомендации по использованию

### Для разработки плагинов:

1. **Используйте movian.d.ts** для базовых интерфейсов
2. **Подключайте movian/page.d.ts** для работы со страницами
3. **Изучайте .js.examples.js** для практических примеров
4. **Проверяйте .d.ts** для доступных методов

### Пример импорта:

```typescript
/// <reference path="../movian.d.ts" />
/// <reference path="./movian/page.d.ts" />
/// <reference path="./movian/http.d.ts" />

// Теперь доступны все интерфейсы
const page = new Page();
const item = page.appendItem(url, "video", metadata);
```
